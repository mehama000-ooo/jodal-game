# 나르미와 달이의 조달 대작전

조달청의 일을 쉽고 재미있게 알리는 웹 게임이에요.
플레이어는 조달청 새내기 직원이 되어, 조달청 캐릭터 나르미·달이와 함께 마을의 평범한 하루를 지켜요.

## 실행 방법

`index.html` 파일을 더블클릭하면 브라우저에서 바로 실행돼요.
폰트와 그림이 모두 파일 안에 들어 있어서 인터넷 연결 없이도 동작해요.

## 스테이지

1. **나라장터에서 공정하게 사기** – 몰래 짠(담합) 업체를 찾아내고, 조건에 맞는 업체와 계약해요.
2. **숨은 혁신제품을 찾아라** – 장터에 숨은 새 기술을 찾고, 혁신제품이 작은 기업을 어떻게 돕는지 알아봐요.
3. **원자재 창고를 지켜라** – 원자재를 미리 비축하고, 가격이 오를 때 공장에 나눠 줘요.
4. **꾀돌이의 반격** – 3분 안에 소방관에게 필요한 방화복을 공정하게 구해요.

## 점수

- 세금 절약: 좋은 물건을 알맞은 가격에 샀을 때
- 공정: 수상한 업체를 찾아내고 규칙을 지켰을 때
- 시민 행복: 마을 사람들이 필요한 것을 제때 받았을 때

## 참고

- 게임에 나오는 업체, 제품, 가격, 사건은 조달청의 일을 쉽게 알리기 위해 지어낸 이야기예요.
- 나르미·달이 캐릭터는 조달청의 공식 캐릭터예요.
